# 📊 Sales Intelligence Hub

A professional-grade Business Intelligence (BI) dashboard and multi-branch sales management system built with **Streamlit**, **Python**, and **MySQL**.

![Database](https://img.shields.io/badge/Database-MySQL-orange)
![Framework](https://img.shields.io/badge/Framework-Streamlit-red)

## 🚀 Overview
Transform raw sales data into actionable business intelligence. This hub allows for real-time tracking of branch performance, customer collections, and product trends through a sleek, interactive dashboard.

## ✨ Key Features
- **Centralized Dashboard**: Track KPIs like Revenue, Collection Rate, and Avg Order Value.
- **Role-Based Access**: Specialized views for Super Admins and Branch Managers.
- **Smart Data Editing**: Direct inline editing of sales records with automatic database syncing.
- **Advanced Exporting**: Download reports in CSV, Excel, JSON, and PDF formats.
- **Interactive Visuals**: Beautifully styled charts for trends, product mix, and payment channels.

## 🛠️ Tech Stack
- **Frontend**: Streamlit
- **Backend**: Python (Pandas, SQL)
- **Database**: MySQL
- **Visualization**: Plotly

## 🚦 Quick Start
1. **Install Dependencies**: `pip install -r requirements.txt`
2. **Setup Database**: Execute scripts in the `database/` folder.
3. **Configure Connection**: Update `app/db_connection.py`.
4. **Run App**: `streamlit run dashboard/streamlit_app.py`
