📊 Sales Intelligence Hub



&#x20;   Sales Intelligence Hub is a comprehensive, enterprise-ready dashboard designed for multi-branch sales tracking and financial monitoring. Built with Python, Streamlit, and a robust SQL backend, this application transforms raw transactional data into high-level business intelligence, enabling smarter decision-making and seamless branch management.



✨ Key Features



Dynamic Executive Dashboard: Monitor real-time KPIs including Total Revenue, Collection Efficiency, Average Order Value (AOV), and Outstanding Receivables.

Advanced Visual Analytics: Interactive visualizations for Sales Revenue Trends, Product Mix, and Payment Channel distribution powered by Plotly.

Role-Based Access Control (RBAC): Secure login system with tiered access for Super Admins (Global enterprise view) and Branch Managers (Localized branch monitoring).

Full Sales Management (CRUD): Complete lifecycle management for sales records with an integrated, editable data grid for rapid updates.

Granular Payment Tracking: Track complex payment cycles by recording multiple payment splits for individual sales, automatically managing "Open" and "Closed" statuses.

Professional Data Export: Generate and download business-ready reports in multiple formats including PDF, Excel, CSV, and JSON.

Custom BI Query Tool: An integrated SQL interface for Super Admins to execute custom queries and perform deep-dive data exploratory analysis.

Premium UI/UX: A modern, responsive interface featuring the Inter typography system, sleek glassmorphism-inspired components, and smooth micro-animations.



🚀 Tech Stack



Frontend: Streamlit (Custom CSS/Glassmorphism)

Visualizations: Plotly Express \& Graph Objects

Data Processing: Python (Pandas \& NumPy)

Database: SQL Backend (MySQL/PostgreSQL)

Reporting: FPDF (PDF Generation), OpenPyXL (Excel Export)
